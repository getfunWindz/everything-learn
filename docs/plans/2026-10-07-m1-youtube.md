**Goal:** 在 everything-learn 中新增 YouTube 适配器：链接 → 元信息 → 字幕（人工优先/自动字幕清洗）→ 无字幕走 Whisper → 产出统一三件套与中文学习报告。

**Architecture:** 纯增量：`providers/youtube.py` 实现 `SourceAdapter`，复用 `core.pipeline` 全部能力（分级/复检/Whisper/产物/缓存）。新增一个核心小改动：`ContentResult.label`（让适配器标注来源，如「字幕(自动)」，报告元信息可显示）。不引入 ffmpeg（字幕/音频/视频流均直链下载）。

**Tech Stack:** `yt-dlp`（已装 2026.08.19，pip 最新）、requests、faster-whisper（可选兜底）

| 5 | 可得性 | 自动字幕 json3 可**直连下载**（实测 HTTP 200，5910 事件）；音频 m4a（format 140）直链；最低视频流可选（排除 storyboard mhtml） | json3 实测事件样例：t=199ms d=4721ms "hi everyone so by now…" |
| 6 | **结论** | **✅ 可自动化**（推荐）：字幕优先（人工 > 自动）→ 无字幕走音频 Whisper；维护成本 = yt-dlp 版本跟进 | — |

**已知特殊点（实现必须处理）**：

- 自动字幕 json3 是**滚动式**（事件重叠、同一句会重复出现）→ 需要去重/合并清洗，并有专门测试。
- 直链 URL 带时效（约数小时）→ `fetch_media_url` 必须**调用时即取**（流水线正好是这样的时序）；适配器内做短期缓存避免同一 item 重复提取。
- 视频流最低清晰度要排除 storyboard（ext=mhtml）。
- 116 分钟级长视频依赖字幕路径（Whisper 兜底代价高，符合现有"长视频"策略）。

class YtDlpMissing(Exception): ...
_yt_dlp_module = None
def _load_ytdlp():
    """懒加载 yt-dlp；未安装给出安装提示"""
    global _yt_dlp_module
    if _yt_dlp_module is None:
        try:
            import yt_dlp
            _yt_dlp_module = yt_dlp
        except ImportError as e:
            raise YtDlpMissing("未安装 yt-dlp，请执行: pip install yt-dlp") from e
    return _yt_dlp_module

_VID = re.compile(r"^[0-9A-Za-z_-]{11}$")
_WATCH = "https://www.youtube.com/watch?v={}"

@register
class YouTubeAdapter:
    name = "youtube"; kinds = {"video"}
    def __init__(self, client=None): self.lang = None; self._info = {}
    def match(self, url) -> bool: ...        # youtube.com/watch|shorts|playlist / youtu.be

    def list_items(self, ref): ...            # playlist → extract_flat 展开；单项 → [ref]

## 风险与对策

- **YouTube 反爬（SABR/PO token）**：提取失败时给「升级 yt-dlp / 配置 cookies」的明确提示；doctor 常显版本。
- **自动字幕质量**：滚动去重 + 覆盖率防线（<50% 判 suspect）；报告端可标注「字幕(自动)」提醒读者。
- **长视频耗时**：字幕路径无转写开销（116 分钟视频实测提取秒级）；Whisper 仅兜底。
- **播放列表规模**：`extract_flat` 快速展开；批量沿用间隔/续跑机制。
